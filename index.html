웹앱 형태 APK가 아니면 플레이 버튼이 활성화되지 않습니다. 아래 안내를 확인하세요.

실제 실행 - 클라우드 안드로이드

이게 진짜 플레이 부분이다. 브라우저 자체는 네이티브 APK를 못 돌리니까, APK를 클라우드 안드로이드에 올려서 그 화면을 브라우저로 스트리밍 받아 조작한다. PC, 아이폰 모두 브라우저만 있으면 된다. 대신 클라우드라서 무료 플랜은 분/세션 제한이 있고, 고사양 게임은 PC 에뮬레이터보다 느릴 수 있다.

주의: 이 단계부터는 파일이 이 기기가 아니라 Appetize 서버로 전송된다. 위의 로컬 분석과 다르다. 개인 정보가 든 APK, 남의 유료 앱 APK는 올리지 마라. API 토큰은 이 브라우저의 localStorage에만 저장되고, 이 사이트에는 서버가 없어서 내가 볼 수 없다.

1. 토큰 받기 (무료, 1번만): Appetize 사이트에서 무료 계정을 만들고, 대시보드의 API Tokens에서 토큰을 발급받아 아래에 붙여넣는다. 2026년 기준 무료 플랜은 월 30분, 세션당 3분 제한이라는 안내가 있다. 정확한 현재 조건은 Appetize 요금 페이지에서 다시 확인해라.
2. APK 선택: 위에서 APK를 먼저 선택해라. 샘플 웹-APK는 진짜 안드로이드 앱이 아니라서 클라우드 업로드가 실패한다. 진짜 APK 파일로 테스트해라.
3. 실행: “클라우드에 업로드하고 실제 실행”을 누르면 업로드 후 클라우드 화면이 아래에 뜬다. 화면을 클릭/드래그해서 조작하면 된다.

아직 클라우드 세션이 없다.

Appetize 새 탭으로 열기

가입 없이 바로 해보고 싶으면 - ApkOnline

가입 없이 쓸 수 있는 무료 클라우드 안드로이드도 있다. 아래 버튼으로 ApkOnline을 열고, 거기서 Run을 누른 뒤 파일 관리자에서 APK를 업로드해서 설치하면 된다. 단점: 안드로이드 8 수준의 오래된 이미지, 100MB 정도가 실질 한도, 광고가 많고, 세션을 닫으면 지워진다. 토큰이 없어서 우리 플레이어 안에 자동 임베드는 안 되고, 새 탭에서 직접 해야 한다.

기기별 실행 안내 — 솔직한 한계부터

브라우저 안에서는 안드로이드 네이티브 코드(DEX)를 직접 실행할 수 없습니다. 그래서 이 플레이어는 분석 + 에셋 미리보기 + 웹앱 APK 실제 플레이까지는 브라우저로 하고, 네이티브 앱의 진짜 실행은 기기별 정식 방법으로 연결합니다. 아이폰은 APK 자체를 설치할 수 없는 구조라, 웹앱 APK 플레이 또는 클라우드 안드로이드가 대안입니다.

PC에서 네이티브 APK 실행하기
1. BlueStacks 또는 Android Studio 에뮬레이터를 설치합니다.
2. 에뮬레이터에 APK를 드래그해서 설치합니다.
3. 출처를 알 수 없는 APK는 설치하지 마세요.
안드로이드에서 실행하기
1. APK 파일을 기기에 저장합니다.
2. 파일 앱에서 APK를 눌러 설치합니다.
3. 처음에는 “알 수 없는 출처 설치 허용”을 물어볼 수 있습니다. 믿을 수 있는 파일에만 허용하세요.
아이폰에서
1. APK는 iOS에 설치할 수 없습니다.
2. 같은 앱의 iOS 버전을 스토어에서 찾으세요.
3. 웹앱 형태 APK라면 이 플레이어에서 바로 플레이할 수 있습니다.
4. 네이티브 앱을 꼭 써야 하면 클라우드 안드로이드(Appetize, Genymotion Cloud 등 유료 서비스) 스트리밍이 필요합니다.

이 사이트는 어떤 APK도 서버에 업로드하지 않습니다. 분석, 해시 계산, 플레이가 모두 이 브라우저 안에서 일어납니다.
