오늘급식표

학교 검색 한 번으로 오늘 급식, 시간표, 수행평가 D-day까지. 전국 초·중·고등학교, 무료.

1. 학교 찾기

학교 이름을 입력하고 검색을 눌러주세요. 선택한 학교는 이 기기에 저장됩니다.

2. 날짜 · 학년 · 반

시간표는 NEIS 시간표를 쓰지 않고, 아래에서 직접 입력한 표만 표시합니다. 급식 데이터 출처: 나이스 교육정보 개방 포털(NEIS Open API). 키 입력 없이 바로 조회됩니다.

오늘 급식

학교를 선택한 뒤 불러오기를 눌러주세요.

시간표 (직접 입력)

직접 입력한 시간표가 없습니다. 아래에서 월~금 시간표를 입력하고 저장하세요.

내 시간표 직접 입력

시간표는 NEIS에서 가져오지 않습니다. 여기서 직접 입력한 표가 시간표 칸에 표시됩니다. 이 기기에만 저장됩니다.

수행평가 · 시험 D-day

D-day는 이 브라우저에만 저장됩니다. 다른 기기에서는 다시 입력해야 합니다.
